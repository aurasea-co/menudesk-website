# menudesk-ai

Marketing site for MenuDesk.ai — operational intelligence for cafes, bakeries,
and restaurants in SEA. Bilingual TH/EN. Audience: F&B owners.

## Content Structure
- `content/th/` — Thai page content drafts (default language)
- `content/en/` — English page content drafts
- `design/` — Site-specific design files
